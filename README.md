# Neurone · Fisioterapia Neurológica

Projeto de comunicação (site + Instagram) da **Dra. Fernanda Iotti** — fisioterapia neurológica e reabilitação neurofuncional domiciliar e online em São Paulo.

| Pasta | Conteúdo |
|---|---|
| `site/` | Site estático de uma página para **fisioterapianeurone.com.br** (`index.html`, `styles.css`, `assets/`) |
| `docs/01-estrategia-instagram.md` | Posicionamento, escolha do @, passo a passo do perfil, bio, destaques, pilares, calendário, banco de ideias, fórmula de post de KPI, métricas e regras éticas |
| `docs/02-identidade-visual.md` | Logo, paleta, tipografia, templates e guia de fotos |
| `posts/` | Templates de posts em HTML + PNGs prontos em `posts/png/` (`node posts/render.js` para gerar de novo) |

## Publicar o site
É HTML puro: suba a pasta `site/` em qualquer hospedagem estática (Netlify, Vercel, Cloudflare Pages, GitHub Pages ou Hostinger/Locaweb) e aponte o domínio `fisioterapianeurone.com.br`.
